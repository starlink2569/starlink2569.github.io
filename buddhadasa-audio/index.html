เก็บในเครื่องของผู้ใช้

คู่มือใช้งานภาษาไทย

  1. พิมพ์คำค้น เช่น ชื่อตอน เลขตอน หรือหมวดหมู่ในช่องค้นหา
  2. ตอนที่ขึ้นสัญลักษณ์ 🎧 จะเล่นในหน้าเว็บได้ทันทีจากไฟล์ static ที่ฝังมากับเว็บ
  3. ตอนอื่น ๆ ที่ยังไม่มีไฟล์ local จะเปิดผ่าน OneDrive preview แทน เพื่อคงต้นทุน 0 บาท
  4. กด ♡ เพื่อบันทึกเป็นรายการโปรดในเครื่องนี้
  5. ใช้ Shuffle เพื่อสุ่มตอน และ Repeat เพื่อวนซ้ำโหมดเล่น
  6. กด Share เพื่อส่งลิงก์แอปหรือคลิปเสียงให้เพื่อนทาง Line/Facebook/Telegram
  7. กด “ติดตั้งแอป” หรือ Add to Home Screen บน iOS/Android เพื่อใช้เหมือนแอป

หมายเหตุเรื่องการเล่นเสียง

เวอร์ชันฟรี 100% นี้ใช้ static hosting เป็นหลัก จึงพยายามเล่นจากไฟล์ที่ฝังมากับเว็บก่อน และ fallback ไปที่ OneDrive public preview สำหรับตอนที่ยังไม่ได้ย้ายมาเป็นไฟล์ static ค่ะ

ยังไม่ได้เลือกตอนเลือกเสียงธรรมะเพื่อเปิดฟัง
